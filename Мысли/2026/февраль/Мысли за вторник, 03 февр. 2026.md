1. Перезапустить Unity для обновления кэша скриптов
2. Создать SettingsDatabase ScriptableObject через Create > Settings > Database
3. Добавить настройки в SettingsDatabase с ключами:
	- musicVolume (Float, 0-1)
	- sfxVolume (Float, 0-1)
	- isFreeGame (Bool)
	- isGivingPrizes (Bool)
	- startLivesCount (Int)
	- livesIncreasedByCredits (Int)
	- isFullscreen (Bool)
4. Привязать SettingsDatabase к компоненту SettingsManager в префабе Globals
