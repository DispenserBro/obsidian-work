# Про ввод текста
## Возможные решения:
### Решение 1: Циклическая навигация (рекомендую)

Самое простое и элегантное - сделать wrap-around навигацию:
- При нажатии "вверх" на первом элементе → перейти на последний
- При нажатии "вверх" повторно → двигаться циклически
**Плюсы:**
- Минимальные изменения кода
- Интуитивно понятно
- Используется во многих аркадах

### Решение 2: Зеркальная навигация

"Лево/Право" дублируют "Вверх/Вниз" в вертикальных меню:
- Влево = Вверх
- Вправо = Вниз (эмуляция)
**Плюсы:**
- Не нужна кнопка "вниз"
- Логично для вертикальных списков
**Минусы:**
- Может быть неинтуитивно

### Решение 3: Автопрокрутка списка

При длительном удержании "вверх" → меню автоматически прокручивается:
- Короткое нажатие = на 1 элемент вверх
- Долгое удержание = быстрая прокрутка вверх, потом wrap на низ

### Решение 4: Контекстная кнопка

Одна кнопка выполняет разные функции в зависимости от позиции:
- Если курсор на первом элементе: "вверх" → переход в конец
- Если на группе: "вверх" → свернуть/развернуть
 
## Моя рекомендация:
### Комбинированный подход:
- Циклическая навигация для всех вертикальных меню
- Горизонтальные кнопки для:
	- Изменения значений слайдеров
	- Переключения опций (влево/вправо)
	- Свернуть/развернуть группы настроек
- "Вверх" в особых случаях:
	- На заголовке группы = свернуть/развернуть
	- На первом элементе = wrap в конец списка
