## Изображения

### Генерация

#### 1) Объект на прозрачном фоне (PNG)

- RU: `Реалистичный [объект], изолированный, без тени под ним, чистые края, PNG с прозрачным фоном, высокое качество, размер [3000×3000]. Никакого текста, водяных знаков или рамок.`
- EN: `Realistic [object], isolated, no ground shadow, clean edges, PNG with transparent background, high quality, size [3000×3000]. No text, no watermark, no frame.`

#### 2) Персонаж/маскот на прозрачном фоне

- RU: `Мультяшный персонаж [кто/что], дружелюбный, простой читаемый силуэт, толщина линий средняя, ровная заливка, PNG с прозрачным фоном, размер [2048×2048].`
- EN: `Cartoon character [who/what], friendly, readable silhouette, medium line weight, flat colors, PNG with transparent background, size [2048×2048].`

#### 3) Жанр/стиль (подставь любой стиль)

- RU: `[сцена или объект] в стиле [киберпанк / акварель / изометрия / low-poly / пиксель-арт 16-bit / вектор flat / масляная живопись / чертёж blueprint / бумажная аппликация / аниме / фотореализм], аккуратные детали, контраст [мягкий/высокий], палитра [холодная/тёплая], размер [1920×1080].`
- EN: `[scene or object] in [cyberpunk / watercolor / isometric / low-poly / 16-bit pixel art / flat vector / oil painting / blueprint / papercraft / anime / photorealistic] style, tidy details, [soft/high] contrast, [cool/warm] palette, size [1920×1080].`

#### 4) Точный ракурс и композиция

- RU: `[объект/сцена], ракурс [перпендикулярно фронтально / трёхчетвертной], кадрирование [по пояс/в полный рост/только фасад], центр композиции на [объект], симметрия [да/нет], размер [1080×1920].`
- EN: `[object/scene], camera angle [orthographic front / three-quarters], framing [waist-up/full body/facade only], center focus on [object], symmetry [yes/no], size [1080×1920].`

#### 5) Ночной город / архитектура (в духе твоих задач)

### Редактирование

#### A) Лёгкая мультяшность лица, сохранить черты

- RU: `Взять исходное фото. Добавить лёгкий мультяшный эффект, сохранить узнаваемые черты лица и пропорции, кожа естественная, без “пластика”, усилить чистоту краёв, остальное без изменений.`
- EN: `Use the original photo. Apply a light cartoon pass while keeping facial features and proportions recognizable, natural skin (no plastic look), crisp edges, leave everything else unchanged.`

#### B) Замена текста/логотипа на объекте

- RU: `Взять исходное изображение. На [область/табличка/шарфик] нанести надпись “[ТЕКСТ]” белыми буквами, аккуратная интеграция по перспективе и освещению, ничего кроме этого не менять.`
- EN: `Use the source image. On the [area/sign/scarf], add text “[TEXT]” in white, match perspective and lighting, change nothing else.`

**C) Изменение цвета/материала**

- RU: `Взять исходное изображение. Перекрасить [объект/часть] в [цвет], сохранить текстуры и блики материала, остальное без изменений.`
- EN: `Use the source image. Recolor [object/part] to [color], preserve material texture and highlights, keep everything else.`

**D) Добавить/включить окна в фасаде**

- RU: `Взять исходное изображение. Сделать часть окон “включёнными” тёплым светом, распределить случайно, яркость умеренная, не менять композицию и цветокор.`
- EN: `Use the source image. Turn some windows “on” with warm light, random distribution, moderate brightness, keep composition and grading.`

**E) Упростить детализацию**

- RU: `Взять исходное изображение. Снизить мелкую детализацию, более гладкие заливки, мягкие тени, контуры чуть толще, стиль ближе к мультяшному.`
- EN: `Use the source image. Reduce fine detail, smoother fills, softer shadows, slightly thicker outlines, more cartoon-like.`

**F) Расширить холст (outpainting)**

- RU: `Взять исходное изображение. Расширить холст [слева/справа/сверху/снизу] на [N%], правдоподобно продолжить фон и структуру сцены, сохранить стиль.`
- EN: `Use the source image. Extend canvas [left/right/top/bottom] by [N%], plausibly continue background/structure, keep style.`

**G) Удалить фон**

- RU: `Взять исходное изображение. Аккуратно удалить фон, оставить только [объект], сгладить края, вернуть PNG с прозрачным фоном.`
- EN: `Use the source image. Cleanly remove background, keep only [object], anti-aliased edges, return PNG with transparent background.`

**H) “Изменить, но минимально”**

- RU: `Взять исходное изображение. Внести только указанные правки: [список]. Все остальные пиксели по возможности оставить без изменений.`
- EN: `Use the source image. Apply only these edits: [list]. Keep all other pixels unchanged if possible.`

### Быстрые подсказки

- **Разрешение/соотношение:** указывай точный размер (напр. 1080×1920) или цель (напр. “для печати A4 300 DPI”, “для Telegram 1080×1080”).
- **Фон:** “PNG с прозрачным фоном” — когда нужен изолированный объект/стикер/лого.
- **Чистота:** добавляй “без текста/водяных знаков/рамок/лишних объектов”.
- **Детализация:** “низкая/средняя/высокая”, “гладкие поверхности”, “минимум шума”.
- **Вариации:** “создай N вариаций, сохранив композицию/стиль”.

## Код

### Редактура кода

**1) Приведи стиль/чистку без изменения логики**

- RU: `Отредактируй код ниже без изменения поведения: выровняй стиль, единый нейминг, убери мёртвый код, добавь короткие комментарии к неочевидным местам. Верни результат целиком. Язык: [C++/C#/Python/…]. Код: ```[вставь код]```.`
- EN: `Edit the code below without changing behavior: unify style/naming, remove dead code, add brief comments to non-obvious parts. Return the full result. Language: [C++/C#/Python/...]. Code: ```[paste code]```.`

**2) Только минимальные правки (diff)**

- RU: `Сделай только минимальные правки для читаемости (переименуй переменные, вынеси магические числа в константы). Формат ответа — unified diff. Код: ```[код]```.`
- EN: `Perform minimal readability fixes only (rename vars, extract magic numbers to constants). Answer in unified diff format. Code: ```[code]```.`

**3) Комментарии и докстринги**

- RU: `Добавь докстринги/комментарии по публичным функциям и неочевидной логике. Не меняй сигнатуры и поведение. Язык: [..]. Код: ```[код]```.`
- EN: `Add docstrings/comments for public functions and non-obvious logic. Don’t change signatures or behavior. Language: [..]. Code: ```[code]```.`

- EN: `Refactor without changing external API: remove duplication, extract pure functions, enforce SRP. Return code + brief rationale. Code: ```[code]```.`

- EN: `Propose a modular structure: layers [UI/Domain/Infra], interfaces for [x], DI points. Return diagram, interface pseudocode, and a migration plan from current code: ```[code]```.`

### Оптимизация

**8) Unity/C# (снижение GC allocs, кадры)**

## Текст

### Редактура текста

**1) Корректура без изменения смысла**

- RU: `Отредактируй текст без изменения смысла: орфография, пунктуация, ясность, плавные переходы, единый стиль. Жанр: [деловой/нейтральный/художественный]. Текст: "[вставь]".`
- EN: `Copyedit without changing meaning: spelling, punctuation, clarity, smooth transitions, consistent style. Register: [business/neutral/creative]. Text: "[paste]".`

**2) Минимальные правки (покажи отличия)**

- RU: `Сделай только минимальные правки читаемости. Верни diff: ~удалено~, **добавлено**. Текст: "[вставь]".`
- EN: `Apply minimal readability fixes only. Return a diff: ~removed~, **added**. Text: "[paste]".`

**3) Сжатие в активный залог**

- RU: `Перепиши в активном залоге, укорачивая фразы, убери канцеляризм. Целевой объём: [N] слов. Текст: "[вставь]".`
- EN: `Rewrite in active voice, tighten phrasing, remove bureaucratic wording. Target length: [N] words. Text: "[paste]".`

**4) Выравнивание стиля под гайд**

- RU: `Приведи к стилю "[название гайда]": термины, капитализация, формат дат/чисел, тон. Отметь отклонения списком. Текст: "[вставь]".`
- EN: `Align to "[style guide]": terminology, capitalization, date/number formats, tone. List any deviations. Text: "[paste]".`

### Изменение/трансформация текста

**5) Парафраз с сохранением смысла (3 варианта)**

- RU: `Перефразируй без потери смысла, дай 3 стилистически разные версии: [нейтральная/деловая/разговорная]. Текст: "[вставь]".`
- EN: `Paraphrase without meaning loss; provide 3 stylistically distinct versions: [neutral/business/conversational]. Text: "[paste]".`

**6) Смена тона**

- RU: `Перепиши в тоне: [дружелюбный/экспертный/вдохновляющий/строгий/юмористический], сохрани факты. Текст: "[вставь]".`
- EN: `Retone to: [friendly/expert/inspiring/strict/humorous] while preserving facts. Text: "[paste]".`
